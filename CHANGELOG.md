## 0.36.0 - 2026-11-12

Commit `eacd7c38ad47`; release record `pub:sha2-256:sfy4uoqakrabuailb5ubkg3wks6jzj3ndojdb27b6rtmtbcuvfia`.

### Changed

The dependency review leaves the owner's own reusable workflows and actions, which carry no license GitHub reads, out of its license check alone: pubkit sync lists those a repository's workflows call in .github/dependency-review-licenses.txt, of which the review takes only the owner's, and without the file it leaves out pubkit's and pubrel's; advisories still apply to them
- The dependabot.yml pubkit sync writes no longer opens pull requests that move the owner's pubkit or pubrel pins: every github-actions entry ignores <owner>/pubkit/* and <owner>/pubrel/*, ahead of any ignores given in security.dependabot.options.
